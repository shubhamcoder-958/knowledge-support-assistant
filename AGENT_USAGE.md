# AI Agent Usage

This project was developed using Google Gemini together with ChatGPT as development assistants.

---

## AI Tools Used

- Google Gemini API
- ChatGPT

---

## Representative Prompts

Examples of prompts used during development:

- Design a knowledge-grounded customer support workflow.
- Improve the AI prompt for structured JSON output.
- Generate a Zod schema for AI responses.
- Refactor the Gemini API route.
- Improve Tailwind UI layout.
- Add approval workflow for support agents.
- Suggest improvements for error handling.
- Generate follow-up questions from missing information.
- Validate structured AI responses.

---

## Work Delegated to AI

AI assisted with:

- Prompt engineering
- API route structure
- UI layout suggestions
- Error handling improvements
- TypeScript refactoring
- JSON schema generation
- Response validation
- Documentation drafting

Final implementation, integration, testing, debugging, and architectural decisions were completed manually.

---

## Important Rejected Suggestions

The AI suggested:

- Automatically sending customer replies
- Automatically executing internal actions

These suggestions were intentionally rejected because the assignment requires a human approval workflow.

---

## Verification

All AI-generated code was manually reviewed.

Verification included:

- TypeScript compilation
- Runtime testing
- Manual prompt testing
- JSON validation using Zod
- API response inspection
- Human review of generated responses

---

## Human Oversight

The application requires manual approval before:

- Customer responses
- Internal actions

The AI cannot perform actions autonomously.
